# ShopCart

A small working shopping-cart library: integer-cent money handling, coupons, checkout totals, shipping rules, inventory reservations, and customer validation.

Requires Node.js 24. No packages, database, or network services are needed.

Run `npm test` to execute six test files. Run `npm run demo` for a checkout example. The upload adapter treats each test file as one test unit, with independent actual outcomes and assertions inside it.
