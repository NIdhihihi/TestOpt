# TestOpt Design System

## Direction

Professional, calm, and operational. Prioritize readable status, time, and test-selection data.

## Existing visual language

- Inter and system sans-serif fonts.
- Light green-gray background with white cards.
- Teal primary actions.
- Green success, red failure, and amber warning states.

## UX requirements

- Label forms and show clear errors.
- Include loading and empty states.
- Keep layouts responsive.
- Never rely on color alone for status.
